# 🧵 ThreadCraft

A modern and responsive fashion e-commerce web application built using **React**, **Vite**, and **Tailwind CSS**. ThreadCraft delivers a premium online shopping experience with a clean UI, reusable components, and scalable architecture inspired by real-world fashion brands.

---

## 📖 Overview

ThreadCraft is a frontend-focused e-commerce project designed to simulate a production-level clothing store. The project emphasizes component reusability, responsive design, and maintainable code structure while preparing for future MERN stack integration.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/threadcraft.git
```

Navigate into the project

```bash
cd threadcraft
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
